MASTER'S THESIS · ROS 2 · LIDAR · CONTROL

Tracking-Based Autonomous Navigation System for Factory Intralogistics

Developed an autonomous navigation system using the Neobotix ROX-Diff mobile robot platform. The system tracks the location of a trolley, navigates towards it, performs autonomous docking, couples with the trolley, and transports it to a target location.

The system uses a hybrid localization approach. UWB measurements provide coarse trolley localization, while LiDAR data and geometric feature extraction provide an accurate trolley pose for final alignment and docking.

The complete system was developed and evaluated in multiple simulation environments before being tested on the real robot platform.

22.64 s Average docking time
0.26 cm Mean lateral error
0.003 rad Mean orientation error

DIGITAL TWIN · ROS 2 · GAZEBO

Developing a Digital Twin of the ABB Flexley Tug T702 Mobile Platform

This project involved creating a simulation-ready digital twin of the ABB Flexley Tug T702 mobile platform. The digital twin replicated the robot’s exact dimensions, motion behaviour, physics, sensors, and other important physical properties.

HUMAN-ROBOT INTERACTION · MACHINE VISION

Building a Curious Robot

This project involved transforming an ABB IRB 2600 industrial robotic arm into a human-interactive robot. The goal was to enable the robot to recognize human gestures and react accordingly.

The project consisted of two major parts. The first was a machine-vision system used to detect and recognize human gestures. The second involved sending specific instructions to the robot based on the recognized gesture, allowing it to perform predefined movements and responses.

PATH PLANNING · MOBILE ROBOTS · ALGORITHMS

Comparison of Path-Finding Algorithms for Autonomous Navigation of Mobile Robots

This project focused on comparing the performance of the A*, Dijkstra, and Rapidly-exploring Random Tree (RRT) path-finding algorithms for autonomous mobile-robot navigation in a simulated CERN facility.

The objective was to compute the most optimized path and evaluate the performance of each algorithm. The comparison considered the generated routes, path quality, computational behaviour, and suitability of each method for autonomous navigation.

Python · A* · Dijkstra · RRT · Path Planning · Autonomous Navigation
