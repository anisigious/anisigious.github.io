MASTER'S THESIS · ROS 2 · LIDAR · CONTROL

Tracking-Based Autonomous Navigation System for Intralogistics in Factories

Developed an autonomous navigation system using the Neobotix ROX-Diff robot platform. The system tracks the location of a trolley, performs autonomous docking, couples with the trolley, and transports it to a target location.

The system uses a hybrid localization approach. UWB measurements provide coarse trolley localization, while LiDAR point-cloud data and geometric feature extraction provide an accurate trolley pose for docking.

The system was developed and evaluated in multiple simulation environments before being tested on the real robot platform.

22.64 s Average docking time
0.26 cm Mean lateral error
0.003 rad Mean orientation error
